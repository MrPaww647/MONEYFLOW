# MONEYFLOW v0.3.0 — Advanced Finance System

## Реализовано
- Эвристическое обнаружение вероятных повторяющихся платежей по категории, описанию, типу и интервалам.
- Автоматические локальные SQLite-копии при запуске (до 10 последних), ручное создание и восстановление.
- Финансовый календарь с операциями и прогнозируемыми датами регулярных платежей.
- Умные правила-рекомендации по категориям, денежному потоку и сравнению расходов.
- Раздел банковских интеграций как точка расширения.
- Улучшенные анимации, адаптивность и поддержка `prefers-reduced-motion`.
- Индексы SQLite по датам и категориям.

## Банковская синхронизация
Реальное подключение пока не включено: нужны конкретная страна и банк, официальный API или лицензированный Open Banking-провайдер. Универсального API для всех банков нет. Не вводите в приложение банковские пароли, PIN и одноразовые коды.

## Запуск
Windows 10/11, Node.js 20+:
```bash
npm install
npm start
```
Сборка установщика:
```bash
npm run dist
```

## CSV
Колонки `date,type,amount,category,description`; дата `YYYY-MM-DD`; тип `income`/`expense` или `доход`/`расход`.

## Хранение и ограничения
Данные хранятся локально в SQLite. Автоматические копии — в подпапке `backups` папки Electron `userData`. Обнаружение регулярных платежей — эвристика, не банковское подтверждение. Рекомендации информационные, не финансовая консультация.
