## ◈ О проекте

**MONEYFLOW** — desktop-приложение для управления личными финансами, созданное с акцентом на удобство, аналитику и контроль над собственными деньгами.

Это не просто список расходов. MONEYFLOW помогает увидеть полную картину финансов: от повседневных покупок до регулярных платежей, бюджетов и долгосрочных целей накопления.

Приложение работает локально, а данные хранятся в SQLite.

### Основная философия

- **Простота** — понятный интерфейс без лишней сложности.
- **Контроль** — все доходы и расходы в одном месте.
- **Аналитика** — цифры превращаются в понятную картину финансов.
- **Приватность** — локальное хранение данных.
- **Развитие** — приложение постепенно получает новые инструменты.

## 📥 Установка и запуск

### 1. Требования

- Windows 10 / Windows 11
- Node.js
- npm

### 2. Клонирование репозитория

```bash
git clone https://github.com/MrPaww647/MONEYFLOW.git
```

### 3. Переход в папку проекта

```bash
cd MONEYFLOW/MONEYFLOW
```

### 4. Установка зависимостей

```bash
npm install
```

### 5. Запуск

```bash
npm start
```

### Сборка Windows-приложения

```bash
npm run dist
```

> Примечание: полноценная проверка запуска и сборки на разных конфигурациях Windows ещё предстоит.

## 🔐 Приватность и безопасность

MONEYFLOW создаётся с принципом локального хранения данных.

- Финансовая база хранится локально.
- Используется SQLite.
- Предусмотрено резервное копирование.
- Пользователь может экспортировать свои данные.
- Банковская синхронизация пока не реализована.

**Важно:** определение регулярных платежей является эвристическим прогнозом на основе истории операций, а не подтверждением от банка.
